CST286 · Learning trail

From one gate to a machine that adds

Every computer you have used is built from millions of copies of one tiny part. On this learning trail you start with that part, a Nand gate, and build your way up to a chip that adds numbers. A simulator on this page tests each chip you build and tells you what to look at next.

Where you end up: you can explain how a machine adds numbers using nothing but one kind of gate, because you built every layer yourself.

  1. PredictSay what the chip should do before you build it.
  2. BuildWire it from the chips you already made, and run the tests.
  3. ProbeFlip the inputs and read every wire inside your own chip.

The chips and the HDL on this page follow projects 1 and 2 of Nand to Tetris, a free course by Noam Nisan and Shimon Schocken. The HDL you write here uses the same rules as that course's Hardware Simulator. The adder, the incrementer and the ALU on this page are 4 bits wide so that every case can be tested and shown; the course builds 16-bit versions of the same designs.
