Learning environments

The pilots run inside environments we are building. Both are expressions of Symbiotic Thinking — two active projects:

Active

The Dojo

Aim: every learner practices judgment with an AI coach that pushes back — a practice space they set up once and carry into any AI tool they use.

Taking shape

The Commons

Aim: learning that happens together — a shared space where participants across pilots exchange work, converse, and push each other's thinking.

What tests what

Every pilot runs the whole capability loop — Self-Directed Learner → Integrative Solver → Adaptive Builder → back to SDL. That loop is the framework's engine and no pilot skips a stage. What differs is where each pilot puts the stress, and which of the surrounding concepts (Symbiotic Thinking, Superagency, Human Value) it foregrounds.

How the learning flows

Each pilot runs in short loops. What a loop teaches gets captured in the team repo (conversations → decisions → the pilot's status file), and cross-pilot patterns get promoted into the framework and methodology. The comprehensive picture is assembled from those promoted learnings — that is what this page summarizes.
