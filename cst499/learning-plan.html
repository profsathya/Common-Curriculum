Learning Plan

Week 6 · due Monday 5 October, 11:59 p.m. · 100 points · Graded items

Purpose

Identify what you individually must learn to complete your project, and plan how you will learn it and how you will prove that you did.

Tasks

“You” means you personally, also in a team project: what you must learn, not what the team must.

Paste this into a Google doc and answer each task under it.

Each + opens guidance, one example, a reflection question and a box to write in. Nothing under a + is required.

  1. 1.Identify what you individually must learn to complete the whole project — the skills, tools, concepts or domain knowledge you do not have yet. List each one.
    Guidance, an example, a question, and a place to write

    Guidance

    List the specific skills, tools, concepts or domain knowledge you do not have yet and the project needs — one line each, numbered, because tasks 2 to 5 come back to this list item by item. The list is yours even on a team project: what you must learn, not what a teammate already knows.

    An example, to shape your thinking — not a model to copy

    Item 1 — how the offices that own campus information actually publish and update it (interviews, and one office’s process end to end).
    Item 2 — a form of accessible search on a static site.
    Item 3 — a way for an office to edit its own entry without me.

    Reflection

    Which item did you find hardest to admit to the list?

    Check it yourself — the same criteria, without the AI
    • Each item is a specific skill, tool, concept or piece of domain knowledge — something you could name to a person who would know whether you have it.
    • Each item is something you do not have yet, and the project needs it.
    • The items are numbered, so tasks 2 to 5 can refer to them.
  2. 2.For each item, explain why the build needs it: which part of the work cannot be done, or cannot be done well, without it.
    Guidance, an example, a question, and a place to write

    Guidance

    For each item in your list, name the part of the work that cannot be done, or cannot be done well, without it. One or two sentences per item is enough; the test is that a reader could point at the part of the project you mean.

    An example, to shape your thinking — not a model to copy

    Item 1 — without it, the resource list is wrong the first time an office changes its hours.
    Item 3 — without it, the site dies when I graduate.

    Reflection

    Is there an item whose answer here is weak enough that it should come off the list?

    Check it yourself — the same criteria, without the AI
    • Every item from task 1 has an answer here, labelled with the same number.
    • Each answer points at a part of the project a reader could find — a feature, a step, a decision — not at the project as a whole.
  3. 3.For each item, name the resources you will learn from — a course, documentation, a book, a person, a tool — with links where they exist.
    Guidance, an example, a question, and a place to write

    Guidance

    For each item, name what you will learn from: a course, documentation, a book, a person, a tool. Link each one where a link exists. A person counts as a resource — name them, and say how you will reach them.

    An example, to shape your thinking — not a model to copy

    Item 1 — a 20-minute conversation with the Tutoring Center coordinator (booked for 8 Oct), and Arlene’s administrator feedback from Cabrillo and Gavilan.
    Item 2 — the Pagefind docs (link).

    Reflection

    Which resource is a person, and have you asked them yet?

    Check it yourself — the same criteria, without the AI
    • Every item from task 1 has at least one resource here, labelled with the same number.
    • Each resource is one someone could find: a link where a link exists, a title where it does not, a named person where the resource is a person.
  4. 4.For each item, describe the action steps you will take to learn it: what you will do, in what order, and when.
    Guidance, an example, a question, and a place to write

    Guidance

    For each item, write what you will do, in what order, and when. Small steps with dates beat one big one: a step you can finish in a sitting, with the day you will do it, is one you can check off.

    An example, to shape your thinking — not a model to copy

    Item 1 — 8 Oct: the conversation with the coordinator. 9 Oct: write up the office’s current process in one page. 12 Oct: show it back to the coordinator and correct it.

    Reflection

    Which step could you do today?

    Check it yourself — the same criteria, without the AI
    • Every item from task 1 has steps here, labelled with the same number.
    • Each step says what you will do, and the steps are in the order you will do them.
    • Each step has a date, and the dates fall between now and the mid-term.
  5. 5.For each item, state how you will verify you learned it: what you will be able to show, what it will demonstrate, and what external verification step, if any, you will use to confirm it — a review by someone who knows the area, a test with a real user, a result others can check.

Strong — each item in 1 is something the project cannot be finished without, and 2 says which part; the resources in 3 are ones you have opened, not a search result; the action steps in 4 have dates that fit between now and the The mid-term scopeWhat it is. Checklist — one line per task. Run it on your own draft; your reviewer runs the same list.
