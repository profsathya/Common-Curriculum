Candidate problem spaces

Where your capstone work can come from
Each of these is a real project with real users, open issues, and a documented way in. You pick one, find a gap inside it worth your semester, and make the case in your Sprint 1 proposal. The framing is yours. The quality pressure comes from people outside this classroom.

The sample goals below are illustrative. They show the scale of contribution we expect — you still find and frame your own, and yours does not have to look like the example.

Faculty research projects sit in the same set: Clay’s machine learning work, the kinesiology group, and the aircraft-inspection project are all available as problem spaces.

Two other routes answer the same question. A certification counts if the gap in your preparation is best closed by earning a real credential — same proposal, same checkpoints, same conversations, plus an applied piece that shows the learning in use. And you can propose something outside this list; the bar for that is higher, and you argue for it in your proposal.

Software engineering

Open Food Facts
Open food-product data behind apps used worldwide. Work in apps, APIs, OCR, and data-quality rules.
Sample goal
Tighten how one product category’s nutrition data is validated, so mislabeled entries stop reaching the apps that read the database.
Humanitarian OpenStreetMap
Open mapping for crisis response. Work in geospatial tooling, mapping workflows, and the Tasking Manager.
Sample goal
Add a quality check to the Tasking Manager that flags incomplete mapping before a task can be marked done.
OpenAQ
Global air-quality data. Work in the API, client SDKs, and ingestion pipelines.
Sample goal
Extend a client SDK so one country’s official air-quality index can be retrieved in a single call, with tests.
Programming Historian
Peer-reviewed digital-method tutorials. Work in lesson code, the publishing platform, and testing.
Sample goal
Repair a published lesson broken by a deprecated library, and add a test that catches the next break.

Data science and machine learning

scikit-learn
The standard Python machine-learning library, with documented routes for bug fixes, documentation, tests, and clearly labeled first issues.
Sample goal
Take a documented bug in one estimator from reproduction through to a merged fix with a regression test.
Our World in Data
The open data pipelines and chart platform behind a site journalists and researchers use daily.
Sample goal
Repair or add one dataset’s pipeline so a chart the public reads stays correct when the upstream source updates.
PyPSA-Earth
Open energy-system modeling. Work in data retrieval, modeling, optimization, and country-specific analysis.
Sample goal
Fix hydro-data retrieval for an under-studied country and publish a first least-cost energy model for it.
OpenML
An open platform for sharing datasets, models, and benchmarks. Work in the Python API and reproducibility tooling.
Sample goal
Add a dataset-quality check to the Python client that catches a common metadata error before upload.

Network and security

OWASP ZAP
A web-application security scanner with explicit good-first, good-second, and scan-rule paths. Java, with some JavaScript.
Sample goal
Write a passive scan rule for a vulnerability class ZAP does not yet flag, with tests and documentation.
Zeek
A network-security monitor with active good-first and larger project issues, including protocol-analysis work.
Sample goal
Extend a protocol analyzer to surface a field current detections miss, and demonstrate it firing on a real capture.
Wireshark
The widely used network protocol analyzer. Work in dissectors, capture tools, tests, and documentation. Higher onboarding cost than the others here.
Sample goal
Improve a dissector so a message type currently shown as raw bytes is decoded, with a capture file as the test.

Game development

Godot
An open game engine with paths in engine code, editor tooling, testing, documentation, and demos.
Sample goal
Take a reproducible editor or engine bug from diagnosis to a reviewed pull request. Godot stopped accepting AI-authored contributions in June, so this path asks you to own every line.
Bevy
A Rust game engine that explicitly welcomes new contributors. Work in engine code, examples, documentation, and plugins.
Sample goal
Fill a documented gap for newcomers with a worked example or a small reusable plugin, and carry it through review.
OpenRA
An active C# strategy-game engine and game project. Work in bug fixes, engine behavior, tools, and tests.
Sample goal
Take a reproducible gameplay or tooling bug through diagnosis to a reviewed fix, with the reasoning written up.
