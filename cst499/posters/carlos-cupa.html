Capstone: Troubleshooting Website

The work

Entry-level IT technicians need help turning vague user complaints into organized troubleshooting steps. PacketPath connects each check to a likely cause and fix.

Why it matters: It helps new technicians reduce guesswork, solve problems faster, and explain their solutions clearly.

Decision

I chose a problem library with one complete scenario instead of opening directly to a single troubleshooting case.

Because: It gives entry-level technicians context and lets them choose a familiar support problem before practicing the troubleshooting process.

Obstacle or open question

The project currently has only one fully interactive troubleshooting scenario.

What I did or will try: I organized the site around a problem library and plan to add scenarios for printer, account, and application problems so the troubleshooting method can apply across more IT support situations.
