# Course writing

For student-facing writing or review, read `skills/writing-to-teach/SKILL.md` first.
For assignment or activity pages, also read `skills/writing-assignments/SKILL.md`.
Use `skills/reviewing-course-text/SKILL.md` for the final pass, including copied
questions and AI feedback instructions. Use `skills/README.md` to find other skills
only when the task needs them.

The user's current instructions and approved revisions take precedence over older
examples. Keep writing principles in the relevant skill; this file is the entry point.
For Fall 2026 CST286, CST349, and CST499 assignment records, follow the current
`writing-assignments` skill and each course's `assignments.html`; the CSV instructions
in CONTRIBUTING.md describe the older pipeline.
