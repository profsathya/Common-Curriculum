## Brand (from CTI Brand Guide 2026)

- **Fonts:** Futura PT is primary (print). Jost is the web/draft stand-in used in these HTML files.
- **Colors:** blue `#2A6FAD`, green `#2D875E`, navy `#153857` (complimentary), white, black. No off-brand tints.
- **Logo:** primary logo for the hero; badge tagline is "Learn. Connect. Solve." Clear space ≈ the height of the C; no stretching, recoloring, mixing, or rotating.
- Flat surfaces, color does the separating, title case, no em-dashes.

## The message (leads everything)

**Headline: "Human Value That Grows With AI."** Positive vision in CTI's own terms — no comparative framing. The four commitments that set CTI apart (fundamental question · framework-as-hypothesis · short experiments · developed in ourselves, co-evolving) are the spine.
