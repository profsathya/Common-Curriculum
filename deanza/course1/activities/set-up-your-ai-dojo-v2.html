Set up your AI Dojo

Set up one AI tool as a coach you can return to throughout the course. You bring the observations and decisions. Your Dojo asks questions and tests your reasoning.

There is no submission. Do not use the Dojo for the first half of Sprint 1, where you work without AI.

1. Create your Dojo

Name your project or Gem CIS 501 AI Dojo:

  • ChatGPT: create a project and open Project settings.
  • Claude: create a project and choose Set project instructions.
  • Gemini: create a Gem and use Instructions.

If projects or Gems are unavailable, use a regular chat and provide the instruction and sources at the start of each conversation.

2. Add the method and course context

  • Copy the course source URL with the button below.
https://docs.google.com/document/d/1q4Dpbzr1quGMw-_i5mn99EO4bi-xj-VK-DoAJG13r38/edit
  • Paste it into your Dojo: use Add source in a ChatGPT project, Google Drive in Claude project knowledge, or Knowledge → Drive in a Gemini Gem. The document combines the shared Dojo Core with released course material.
  • If the source cannot be read: paste or upload a dated copy of both tabs. Replace that copy when the document changes.

Copy this instruction into your project or Gem:

Act as my Dojo coach for CIS 501: Reframing Problems with AI. Use the attached Dojo and Course Context document. At the start of each chat, tell me which tabs you accessed and the Course generation date. Ask me for any source you cannot access.

Ask for my thinking first and one focused question at a time. Challenge assumptions without deciding for me or inventing evidence, stakeholder responses, policies, or deadlines. Name the source for course answers, respect directions to work without AI, and follow current Canvas directions when sources differ.

3. Check the setup

Start a chat in your Dojo and ask:

Which sources did you access, and what would you do if I asked you to make a decision for me?

Share one real, non-sensitive uncertainty about learning with AI. Check that the coach:

  • asks for your thinking and follows up on what you said;
  • challenges an unsupported assumption instead of inventing evidence; and
  • leaves the decision with you.

If it cannot access the sources, add the dated copies and try again. You do not submit this conversation.

Use it later

When an activity invites AI use, return to this Dojo with your notes and the activity directions. Keep workplace details appropriate for the tool, and check requirements against Canvas.

Continue to Introduction Post. If setup is blocked, use Canvas Inbox and explain which step stopped you.
